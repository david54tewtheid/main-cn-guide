# main-cn-guide

本仓库用于归档和发布多个独立的 HTML 页面。这些页面各自代表不同的功能模块或信息展示，不针对任何特定的域名或网站。

## 项目简介

这是一个通用型 HTML 页面集合仓库。页面内容涵盖信息展示、工具界面、文档说明等，以静态 HTML 文件形式存放，可直接通过浏览器打开或部署至静态托管服务。

仓库本身不提供服务、不收集数据、不涉及具体商业或运营目标。所有页面均为独立文件，彼此之间无依赖关系。

## 目录说明

```
.
├── README.md          # 本说明文件
├── pages/             # 存放所有 HTML 页面
│   ├── example1.html
│   ├── example2.html
│   └── ...            # 其他页面文件
└── assets/            # 共享资源（图片、样式、脚本等）
    ├── css/
    ├── js/
    └── images/
```

- `pages/`：所有独立 HTML 页面存放于此，文件名即页面标识。
- `assets/`：页面共用的资源文件，按类型分类存放。

## 页面归档说明

- 每个 HTML 文件均为独立、完整、自包含的页面。
- 页面可能引用 `assets/` 目录下的资源，但不会引用外部不可控资源。
- 页面内容可能随时间更新、替换或移除，不保证长期一致性。
- 不承诺任何页面在特定时间内的可用性或内容准确性。

## 维护说明

- 本仓库由维护者不定期更新。
- 欢迎提交 Issue 报告问题或提出建议。
- 不接收针对具体域名、商业推广或诱导性内容的请求。
- 所有新增页面应符合通用、中立、信息性定位。

## 使用方式

1. 克隆或下载本仓库。
2. 在浏览器中打开 `pages/` 目录下的任意 HTML 文件。
3. 或部署至任意静态文件服务器，通过 URL 访问对应页面。
